# 方案骨架、量力校验、降级预案与总结格式

> 第④步把板块选好的内容落成本场可执行方案；校验人 / 时 / 物 / 场地撑不撑得住，撑不住按降级砍。方案另一位老师拿到就能办，不依赖"现场自己把握"。活动后总结的基线格式见第八节。

## 一、方案九要素

1. **背景卡**：分支（防火 / 防震 / 防拐）、主题时间窗口、主办与负责人、参与对象、本场侧重。
2. **场地与路线**：室内教学场地、演练路线、室外集合点；分楼层 / 分批时写明顺序。
3. **环节结构**：宣教 / 演练 / 成人专项 / 外联 / 家园，各环节由谁担、面向谁。
4. **流程时长**：逐环节时段与动作；分钟数为草稿，以现场预案为准。
5. **分工**：总指挥、引导员、清点员、医务联络、器材保障、拍照留痕等角色到人。
6. **物料清单**：图卡 / 视频、广播警报、训练器材、签到表、名册、标识、提示物料。
7. **条件校验**：人手、时间、物料、场地、通知渠道、外联条件是否现成。
8. **安全红线**：幼儿与成人环节分离、撤离秩序、不跳窗不乘电梯、不恐吓不制造恐慌。
9. **留痕清单**：方案、通知、教案、签到清点、照片、专项记录、家园材料、小结。

## 二、流程示例（分钟数均为草稿，以现场为准）

### 防火疏散演练（约 20—30 分钟）

| 时段 | 环节 | 动作 | 责任人 |
|---|---|---|---|
| T-10 min | 动员讲规则 | 说明信号、路线、集合点；重申不推挤、不捡拾 | 总指挥 |
| 0 | 警报触发 | 广播 / 警报；班级前后带队撤离 | 引导员 |
| 0—8 min | 撤离到集合点 | 预定路线，清点员按班清点报数 | 清点员 |
| 8—15 min | 现场小结 | 说顺畅点与改进点；成人器材安排另列时段 | 总指挥 |
| 15—20 min | 有序带回 | 按班带回教室 | 各班教师 |

### 防震避险疏散演练（约 20—30 分钟）

| 时段 | 环节 | 动作 | 责任人 |
|---|---|---|---|
| T-10 min | 动员讲动作 | 说明避险七字诀、信号、撤离路线 | 总指挥 |
| 0 | 避险信号 | 就近躲桌下 / 墙角，伏地、遮挡、手抓牢 | 各班教师 |
| 0—2 min | 保持避险 | 护头蜷曲，不奔跑出门、不跳窗 | 各班教师 |
| 停止口令后 | 震后疏散 | 护头快步行走，预定路线到空旷集合点 | 引导员 |
| 到点后 | 清点小结 | 班级清点报数；小结动作与秩序 | 清点员 / 总指挥 |
| 结束 | 有序带回 | 按班带回教室 | 各班教师 |

### 防拐情景活动（班级时段，约 30—40 分钟）

| 时段 | 环节 | 动作 | 责任人 |
|---|---|---|---|
| 0—10 min | 认知导入 | 绘本 / 图卡讲拒绝要点、求助对象 | 各班教师 |
| 10—25 min | 情景游戏 | 角色扮演：拒绝给食物、不跟走、找老师求助 | 各班教师 |
| 25—35 min | 口诀巩固 | 儿歌 / 拍手游戏；情绪安抚与正强化 | 各班教师 |
| 收尾 | 家园提示 | 带回家庭约定要点 | 家园对接人 |

## 六、降级预案（砍环节，不砍安全红线）

1. **人手不足**：全园演练改为分批 / 分楼层；外联改为园内认知活动；成人专项转为要领演示。
2. **场地受限**：室外集合点换备选；路线改分流；缩短实操时间。
3. **外联未接洽**：不写外部单位到场；改园内教学或家长志愿者协助。
4. **时间紧张**：合并宣教环节，保留疏散演练与清点小结；不取消安全秩序要求。

## 附：跨季度轮换节奏建议（年度参考，非台账）

> 适用场景：园所每季度轮换一类安全活动（防火 / 防震 / 防拐）。本包只给节奏建议与单场衔接说明，**不建年度台账、不排值班排班表**；年度计划仍由园所制度文件与属地安排定。成套年度排期表骨架与示例见 `references/yearly-schedule.md` 与 `examples/yearly-schedule-sample.md`。

- **节奏示例**（非固定要求，以园所与当年属地通知为准）：
  - 秋季、119 消防月前后：防火（宣教＋疏散演练；成人器材实操另列时段）；
  - 春季、安全教育日前后：防震（避险动作＋震后疏散演练）；
  - 其余时段：防拐（情景认知与角色扮演，不搞撤离演练）。
- **场间衔接**：上一场总结里的问题与改进项，作为下一场方案的输入；单场方案仍各自采集背景、场地、人数与条件，旧方案的数字、路线、联系人不沿用到新场。
- **重复频率**：防火、防震演练可按园所预案与属地要求定期开展；防拐以适龄情景教育为主，不重复制造紧张氛围。
- **边界**：防溺水、防踩踏、交通安全等其他安全主题不在本包三分支内，需要时另找对应专题材料。

## 八、活动总结报告基线格式（活动后独立单页）

> 总结为活动后另起对话产出的独立页面，不附在原方案末尾；可打印留档。照片内嵌进 HTML；定量信息以名册 / 现场记录为准，不靠照片推断。基线格式先固定，后续可按园所要求调整。

### 总结稿骨架

```
# 【分支】活动总结

## 一、基本信息
- 活动类型：防火 / 防震 / 防拐
- 活动日期：　｜地点：　｜负责人：　
- 参与对象：班级、幼儿数、教职工 / 安保数

## 二、定量记录
- 参与幼儿：　人；教职工 / 安保：　人；涉及班级：　个
- 演练用时：　；环节完成情况：按方案完成 / 部分调整（写明调整）
- 签到与清点：名册核对情况；缺员及处置（无则写"无"）

## 三、过程简述
（按时间顺序写经过：宣教内容、演练 / 情景过程、外联或家园环节）

## 四、顺畅点
（组织秩序、动作掌握、配合情况等正面记录）

## 五、问题与改进
（现场问题、不足；对应改进措施；不写整体合格 / 达标结论）

## 六、留痕材料归档
方案 / 通知 / 教案 / 签到清点表 / 照片 / 专项记录 / 家园材料清单

## 七、现场照片
（照片内嵌；每张注明环节与拍摄时间，可加简短说明）

## 附：待核实项
【待核实：____】
```

### 总结撰写规则

- **定量优先可核对**：人数、班级、用时优先取自签到名册与现场记录；取不到记【待核实】，不估写。
- **定性写实**：只记观察到的事实与反馈，不写成表彰或责任结论；问题写进改进，不在总结里下"活动成功 / 完全达标"判断。
- **照片受控**：照片只用于园内归档；名单、联系方式不随照片扩散。
- **外联口径**：外部单位到场与否按实际写；未到场不写成已参与。
