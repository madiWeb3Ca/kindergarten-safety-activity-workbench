# 红线与使用规则

> 本文件是所有方案、总结、物料、留痕动作的硬边界。违反任意一条即视为不合格，必须重写。

## 一、事实检索规则

1. 园名、班额、人数、场地、器材数量、联系人、外部单位对接状态，一律以用户确认或现场记录为准；AI 不编默认值。
2. 政策主题、日期、届数、属地要求，以当年官方通知为准；包内不写死年份主题，未核实留【待核实】。
3. 引用政策只写文件名与通用口径，不转述未核实的细则；合规判断由园责任人和属地部门作出。
4. 总结稿的定量信息取自名册 / 现场记录；照片只作过程记录，不靠照片推断人数与时间。
5. 未接洽的外部单位不写成已邀请、已到场；家长参加与否按实际写。

## 二、结论与承诺红线

- 禁止写："零隐患""全部达标""保证不出事""百分百安全""零事故""活动圆满成功、无任何问题"。
- 演练与宣教只记录过程事实；问题进改进闭环，不在方案或总结里下合规结论。
- 不替园所判断"符合 / 不符合规定"；可对照要点提示可能遗漏。

## 三、通用安全边界

- 幼儿只参与认知、观摩与教师带领的疏散 / 避险演练；成人专项环节与幼儿队伍分开。
- 演练中不推挤、不奔跑、不捡拾物品、不逆行；楼梯转角有引导；缺员立即上报。
- 宣教符合 3—6 岁认知：不用恐怖画面、案例、巨响或刺激性模拟近距离对着孩子。
- 方案结尾注明"本稿为活动组织安排，不替代制度文件"。

## 四、分支专项红线

### 防火

- 幼儿不碰明火、不操作灭火器 / 消火栓；器材实操对象仅限教职工、安保、志愿力量。
- 训练用火只在成人专场、安全场地、有指导条件下进行；幼儿观摩为远距离演示。
- 不安排幼儿使用防烟面具等成人器材做实操佩戴（可观摩讲解）。

### 防震

- 避险时不跳窗、不乘电梯、震时不盲目冲出教室；震动停止后再疏散。
- 不讲解建筑结构损毁、伤亡案例；避险动作简化到幼儿可完成。
- 室外集结点远离楼房、围墙、广告牌、电杆、大树。

### 防拐

- 情景模拟温和进行，不使用恐怖陌生人形象、不演暴力情节；结束后及时安抚、正强化。
- 不用"警察抓人""被拐走就见不到爸妈"等话语恐吓孩子。
- 不展开具体骗术细节；隐私部位教育另属专题，本包不展开成独立课程。
- 不组织防拐撤离演练；不安排幼儿独自跟随模拟陌生人离开。

## 五、能力边界（不承接）

- 不搭隐患排查台账体系、不编应急预案、不做设施改造方案、不排值班 / 值守班表。
- 可引用园所既有预案的小组叫法与程序口径，不复制、不改写预案条文，不在活动方案里新编报警、灭火、搜救处置程序。
- 不写行政制度、岗位职责、考核办法；可给活动建议、方案骨架、总结初稿。
- 不替代安全责任人的决策与现场指挥；演练组织以园所预案和现场指挥为准。

## 六、事实口径红线

- 园所表格、文档只读不写；产物在己方账号单开新表 / 新文件。
- 人名、园名、地名、企业名不固化进公共发布包；示例均为演示口径。
- 群通知、家园材料口径发布前人工复核；不代为群发。

## 七、隐私与影像边界

- 幼儿影像、名单、家长联系方式按岗位受控，不全员分发、不进公开共享材料。
- 总结照片只用于园内归档；照片说明不带家庭联系方式。
- 示例与公共版本剥离可识别个人信息。

## 八、占位写法

- **【待填：____】**：对话必问项，出稿前清零；正文残留即不合格。
- **【待核实：____】**：现场盘点或政策核对项，归集文末清单，注明核实方向。
- 两类占位不混用；不把待核实项写成既定事实。
