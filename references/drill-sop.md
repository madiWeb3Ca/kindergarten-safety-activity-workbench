# 三分支活动分步 SOP（防火 / 防震 / 防拐）

> 本文件是**活动组织**的分步编排骨架：每一步谁做、什么时点、用什么、留什么记录。它不是应急预案。真实火情报警、灭火编成、搜救处置，地震后的建筑与人员应急处置，属园所制度预案；方案里只留引用位（见第八节），本包不代写、不改写预案条文。
>
> 岗位均用代称；人名、班级、路线、器材数量以本场采集和现场记录为准，旧件事实不沿用。分钟数为草稿，以现场预案为准。

## 一、适用范围与边界

- **适用**：防火疏散演练、防震避险疏散演练的活动组织编排；防拐为班级情景认知与角色扮演活动，不搞撤离演练，其活动链见第五节。
- **可预置**：环节顺序、通用动作要领、岗位分工框架、留痕材料清单。
- **不写死**：园所小组编成、报警与灭火程序、值班排班、组织制度；这些对齐项目空间旧预案 / 制度件格式，事实由用户确认。
- **三分支性质不同**：防火、防震是"信号 → 动作 → 集合清点"的演练链；防拐是"认知 → 情景练习 → 巩固安抚"的教学活动链，不套用撤离流程。

### 3.2 防火触发响应链（第 2 阶段细化）

> 这一段最容易缺：稿子不能从"警报响了"直接跳到撤离，要把发现、上报、启动、通报、就位写完整。六环依次落位：

1. **模拟起火点设定**：本场演练假设起火的区域（如某楼层 / 某活动室）；由谁扮演"发现人"。属情境设定，不点燃真实明火。
2. **发现与示警**：发现人按约定方式呼喊示警或发出信号，并就近告知周边岗位。
3. **上报**：发现人向总指挥报告情境与位置；总指挥据此判断、宣布进入演练响应。
4. **启动与通报**：总指挥宣布启动演练响应；通过广播 / 哨声 / 口令通报各班与各组；通报口径只讲演练信号与路线，不制造恐慌。
5. **各组就位**：路线引导员到楼梯 / 转角位；清点员随班就位；医务联络到待命位；器材保障确认信号与器材；拍照留痕到位。
6. **班级准备**：班级教师停止活动，组织幼儿起身、按前中后站位，等待撤离指令。

**写成方案时**：这六环可以合并进流程表的"触发响应"行，也可以单列一小节；每环写清动作与责任人，发现人、上报路径、通报方式、就位时点不能空着只写"总指挥发布信号"。

## 四、防震：避险疏散链

> 防震不走"火情发现—上报"链；信号由总指挥直启，按"避险 → 保持 → 停止口令 → 疏散 → 清点"时序编排。政策动作口径见 `policy-basis.md` 第三节。

### 4.1 防震时序表

| 阶段 | 环节 | 时点（草稿） | 主要责任人 | 物料 | 留痕材料 |
|---|---|---|---|---|---|
| 1. 演练前准备 | 动员教避险动作；划定桌下 / 墙角避险位；检查桌椅稳固、远离窗户与吊灯吊扇；踏勘疏散路线与空旷集结点；约定避险信号与停止口令；班级预习七字诀 | 演练前一日—到场前 | 总指挥、各班教师、器材保障 | 方案稿、避险动作图卡、名册、路线图、集结点标识 | 方案定稿、动作教学记录、签到表 |
| 2. 避险信号 | 总指挥发出避险信号；班级教师停止活动，发出避险口令 | 演练开始时点 | 总指挥、各班教师 | 广播 / 哨子、信号约定 | 启动记录 |
| 3. 就近避险 | 幼儿就近躲到桌下 / 承重墙墙角，伏地、遮挡、手抓牢；教师巡视纠正姿势 | 信号后即时 | 各班教师 | — | 避险环节照片 |
| 4. 保持避险 | 护头蜷曲保持姿势，不奔跑出门、不跳窗、不捡拾物品；保持到停止口令 | 避险后约 1—2 分钟（草稿） | 各班教师 | — | 巡视记录 |
| 5. 震后疏散 | 停止口令后护头快步行走，按预定路线到空旷集结点；转角引导分流 | 停止口令后约 5—8 分钟 | 班级带队、路线引导员 | 疏散标识、名册 | 疏散过程照片、路线记录 |
| 6. 集合清点 | 按班列队清点报数；缺员登记上报；医务待命；集结点远离楼房、围墙、电杆、大树 | 到达集结点后 | 清点员、总指挥、医务联络 | 名册、清点表 | 清点记录、缺员上报记录 |
| 7. 小结与带回 | 讲评动作与秩序；有序带回；成人做动作要领巩固（无器材实操）；事后归纳总结 | 清点后 / 活动后另起对话 | 总指挥、各班教师、总结对接人 | 拍照设备 | 小结记录、照片、活动总结 |

### 4.2 避险疏散链六环（逐环落责任人）

1. **信号约定**：演练前约定避险信号（广播 / 哨声 / 口令）与停止口令；各班听清对应动作。
2. **就近避险**：信号响起，幼儿就近进入事先划定的避险位置；伏地、遮挡、手抓牢。
3. **保持避险**：护头蜷曲保持标准姿势，教师巡视提醒；不奔跑出门、不跳窗、不乘电梯。
4. **停止口令**：总指挥发出停止避险口令；班级教师组织起身、整理队伍。
5. **护头疏散**：护头快步行走，按预定路线疏散；前排走前门、后排走后门，就近逐次下楼；转角引导员到位。
6. **集合清点**：到达空旷集结点按班列队清点，缺员上报；与防火集合清点口径一致。

### 4.3 避险动作要领（写进方案"安全注意事项"）

- 避险位置：课桌下（旁）、承重墙根、稳固排椅下（旁）；远离窗户、吊灯吊扇、书柜与易碎玻璃；
- 七字诀：**伏地**（降低重心、蜷曲身体）、**遮挡**（护头颈腹部，头顶不高于桌面）、**手抓牢**（抓住桌腿或庇护物保持稳定）；无庇护物时用手、书本或软垫护头颈；
- 避险时不奔跑出门、不跳窗、不乘电梯、不捡拾物品；
- 疏散时护头、快步行走，不拥挤、不推搡、不喧哗、不争跑、不逆行；
- 集结点选空旷场地，远离楼房、围墙、广告牌、电杆、大树；
- 教师一前一后带队，楼梯转角安排引导；缺员立即报总指挥，幼儿不折返找人。

## 五、防拐：情景认知活动链

> 防拐是班级教学活动，**不组织撤离演练、不安排器材实操**；情景以游戏方式进行，全程温和、可随时叫停。环节编排见下，适龄边界见 `policy-basis.md` 第四节。

### 5.1 防拐活动时序表

| 阶段 | 环节 | 时点（草稿） | 主要责任人 | 物料 | 留痕材料 |
|---|---|---|---|---|---|
| 1. 活动前准备 | 备课与情景台词审定；选定温和情景与角色；道具只用玩具、图卡，无刺激道具；分工到主持、情景配合、观察安抚、拍照；家园告知口径先定 | 活动前一日 | 班级主持教师、配班、行政对接 | 绘本、图卡、口诀卡、道具清单 | 教案、台词审定记录、家园通知 |
| 2. 认知导入 | 绘本 / 图卡讲拒绝要点、可信求助对象、口诀；不讲具体骗术细节与暴力案例 | 活动开始约 0—10 分钟 | 各班主持教师 | 绘本、图卡、口诀卡 | 课堂照片、教案 |
| 3. 情境设置 | 先讲明"这是老师带大家玩的安全游戏"；配合教师就位角色；情景范围限定在班级 / 园内熟悉场地 | 导入后即时 | 主持教师、情景配合 | 情景道具 | 活动记录 |
| 4. 角色扮演练习 | 轮换温和情景：拒绝食物玩具、不跟走、不说家庭信息、走失原地等候 / 找老师求助；观察幼儿反应与掌握情况 | 约 10—25 分钟 | 主持教师、配合教师 | 情景道具、观察记录 | 情景记录、照片、幼儿发言记录 |
| 5. 口诀巩固 | 拍手儿歌 / 口诀复述；对做到拒绝与求助的幼儿正强化，不批评表现犹豫的孩子 | 约 25—35 分钟 | 主持教师 | 口诀卡 | 照片、儿歌记录 |
| 6. 情绪安抚与收尾 | 即时安抚紧张情绪；说明"刚才是游戏，现在老师都在"；家园提示带回家庭接送约定 | 巩固后 | 主持教师、家园对接人 | 群通知模板 | 安抚记录、群截图 |
| 7. 活动后归纳 | 活动后另起对话写总结；记录幼儿反应、顺畅点与改进项 | 活动后 | 总结对接人 | 拍照设备 | 活动总结 |

### 5.2 情景环节清单（温和情景，台词事先审定）

| 情景类别 | 练习动作 | 边界 |
|---|---|---|
| 陌生人给食物 / 玩具 | 摇头摆手拒绝，不接过来，告诉老师 | 道具为普通玩具 / 图卡，不用真实包装食品诱惑 |
| 冒充熟人 / 问路搭话 | 不跟走，留在原地或找在岗老师、保安 | 不演强行拉拽、抱走动作 |
| 询问家庭信息 | 不向陌生人说住址、家人姓名电话 | 小龄儿童信息卡由家园保管，不在班内公开宣读 |
| 走失情境 | 原地等候；向穿制服人员、老师、保安求助；记住 110 | 限定园内熟悉场地，不制造真实走失紧张 |

### 5.3 适龄与情绪要点

- 不使用恐怖陌生人形象，不演暴力、追堵、强行带走情节；不用"警察抓人""被拐走就见不到爸妈"等话语；
- 不展开具体骗术细节，不渲染暴力拐卖案例；
- 情景结束后及时安抚、正强化；幼儿哭闹或紧张即暂停情景，先平复情绪；
- 不把幼儿在游戏中的犹豫表现批评为"胆小"；
- 隐私部位教育属另一专题，本活动点到为止、家园配合，不展开成独立课程。

## 七、动作要领清单（写进方案"安全注意事项"）

### 7.1 防火撤离要领

- 听到信号停止手头活动，跟随班级队伍行动；
- 低姿前行，用湿毛巾 / 手帕捂口鼻（本班自备）；
- 沿预定路线分流行进，不推挤、不奔跑；
- 不捡拾物品、不折返取物；
- 不乘电梯、不跳窗；
- 转角听从引导员指挥，不在楼梯口停留围观；
- 到达集合点按班列队，不自行离队；
- 缺员立即报总指挥，由成人处置，幼儿不折返找人。

### 7.2 防震避险与疏散要领

见 4.3 节。

### 7.3 防拐行为要点

- 不跟陌生人走、不上陌生人的车；
- 不吃、不接陌生人给的食物和玩具；
- 不向陌生人透露家庭住址与家人信息；
- 走失原地等候，或向老师、保安、穿制服的在岗人员求助；记住 110；
- 游戏中拒绝、呼救、求助三步分步练，不要求幼儿当场完美表现。

## 九、与方案稿章节的对应

- 触发 / 情境启动链 → 流程表"触发响应启动 / 情境设置"行或方案"活动流程"节；
- 岗位动作清单 → "分工与职责"表；
- 动作要领 → "安全注意事项"节；
- 异常分支 → "安全预案 / 待核定项"，标注引用园所预案；防拐情绪类异常写本场处置安排；
- 留痕材料 → "留痕清单"；活动后归纳进入活动总结模式，不附在方案末尾。
