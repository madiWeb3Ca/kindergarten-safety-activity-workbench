# 采集清单（方案字段 / 总结字段；对话必问 / 现场待核实 / 政策待核）

> 出稿前对照本清单逐项过。**A 类对话必问**：引导卡逐项问清并填进稿子，正文不再留【待填】；用户当场答不上来，记进待核定清单"会后补"，不在正文散落占位。**B 类现场待核实**：要实地盘点或查记录才能定，保留【待核实】并进待核定清单。**C 类政策待核**：以当年官方通知为准，保留【待核实】。

## 一、方案生成模式

### A 类 · 对话必问（出稿前清零，正文不留【待填】）

| 字段 | 落位 | 没答全时 |
|---|---|---|
| 分支：防火 / 防震 / 防拐 | 背景卡 | 先定分支再往下问 |
| 时间窗口：宣传月 / 消防日 / 安全教育日 / 开学季 / 节假日前 / 园内自排 | 背景卡 | 给选项供选 |
| 主办与负责人 | 背景卡、分工表 | 答不上记待补，不编姓名 |
| 参与对象：幼儿班级 / 教职工 / 安保志愿力量 / 家长代表 / 外部单位 | 背景卡 | 分清幼儿与成人 |
| 本场侧重：宣教为主 / 演练为主 / 综合一场 | 背景卡 | 给选项 |
| 各分工角色人选：总指挥、引导员、清点员、医务联络、器材保障、拍照、家园对接 | 分工表 | 能定几个定几个，未定记待补；两位牵头人如何分工、某层班级走哪个楼梯这类当场能定的，本步收口 |
| 外联意向：是否联系消防站 / 民警 / 社区；家长是否参加 | 外联板块 | 未接洽记为备选，不写已邀请 |
| 场地路线的口述情况：室内场地、疏散路线、室外集合点 | 场地表 | 不确定部分转 B 类 |
| 演练情境与通报（防火）：模拟起火区域、扮演发现人、发现后上报路径、启动通报方式（广播 / 哨声 / 口令） | 触发响应链 | 对话能定的当场收口；真实报警程序不编，引用园所预案 |
| 避险约定（防震）：避险信号与停止口令、就近避险位置、疏散路线与空旷集结点 | 避险疏散链 | 避险位置避开窗户、吊灯吊扇；集结点远离楼房围墙 |
| 情景安排（防拐）：情景类别（拒绝食物 / 不跟走 / 不说家庭信息 / 走失求助）、主持与配合扮演分工、观察安抚安排、台词与道具审定 | 情景活动链 | 情景温和、无强行带走模拟；不组织撤离演练 |
| 现有物料口述：图卡视频、广播警报、训练器材、签到名册 | 物料表 | 数量完好转 B 类 |
| 家园宣传方式：群提示 / 海报 / 亲子任务 | 家园板块 |  |

### B 类 · 现场待核实（保留【待核实】，归集文末清单）

- 场地容量、路线通行条件、集合点是否足够；
- 器材数量、完好状态与存放位置；
- 实际参与名册、班级数与人数；
- 外部单位对接结果、名额、时间；
- 现场布置与标识现状。

### C 类 · 政策待核（保留【待核实】）

- 当年宣传月 / 安全教育日主题、日期、届数；
- 属地教育 / 消防 / 应急 / 公安部门的额外要求或报送时限；
- 是否有固定台账、记录模板或迎检口径。

## 二、活动总结模式

### A 类 · 对话必问（出稿前清零）

| 字段 | 落位 | 没答全时 |
|---|---|---|
| 活动类型：防火 / 防震 / 防拐 | 基本信息 |  |
| 活动日期、地点 | 基本信息 |  |
| 负责人与参与对象（班级） | 基本信息 |  |
| 过程口述：按时间讲经过，宣教 / 演练或情景 / 外联 / 家园各环节 | 过程简述 | 可语音陈述，AI 归纳 |
| 现场照片提交 | 照片章节 | 缺照片先出文字稿，照片位置留位 |
| 顺畅点、印象深的环节 | 顺畅点 | 口述为主，不替下结论 |

### B 类 · 现场待核实（取自名册 / 记录，不估写）

- 参与幼儿人数、教职工 / 安保人数、涉及班级数；
- 演练用时、环节完成情况与现场调整；
- 签到与清点结果、缺员及处置；
- 现场问题、不足与改进措施细节；
- 照片清单：环节、时间、拍摄人。

### C 类 · 政策待核

- 园所归档是否有固定总结模板、份数或上报时限；
- 照片归档的命名、存放位置与可见范围。

## 三、占位写法

- **【待填：____】**：A 类对话必问项，出稿前必须清零；正文出现即不合格。
- **【待核实：____】**：B / C 类，归集到文末"待园方核定项 / 待核实项"清单，逐条写清核实人与方向。
- 数字、人名、单位、联系方式一律不编；答不上来宁可留待核实，也不补默认值。
- 采集来源标注（"口述""录音""语音转写"等）不是正文内容，不留在成稿里；需要溯源时写进文末待核实清单或过程草稿。
