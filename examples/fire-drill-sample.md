# 疏散演练专场方案（示例档案）

> 演示口径：岗位为代称，真实姓名、日期、人数、器材数量、场地条件均为待核定项，人工核对后回填；不构成对外或上报物料。当年主题与属地要求以官方通知为准。

**时间窗口**：11·9 消防日　**主办 / 负责人**：后勤 / 安全负责人（岗位代称，姓名待核定）
**参与对象**：全体幼儿、教职工、安保 / 志愿消防力量　**本场侧重**：疏散演练为主

## 一、背景与目标

- **时间窗口 / 主题**：11·9 消防日；当年宣传月主题【待核实：以当年官方通知为准，不沿用往年】。
- **参与对象**：全园幼儿跟随教师参与疏散；教职工、安保、志愿力量承担引导、清点与器材保障；本场不安排外联参观。
- **本场目标**：
  1. 完成一次全员疏散演练，幼儿听懂警报、按路线撤离到集合点；
  2. 教职工熟悉报警、引导、清点分工，安保力量就位；
  3. 留存演练通知、签到、清点、照片与小结，备检查。

| 宣教铺垫 | 演练前一日班级谈话：认识警报信号、撤离要领、不推挤 | 各班幼儿 | 演练前一日晨间 | 各班班主任 | 绘本、标志图卡 | 谈话记录、照片 |

## 三、演练日流程（草稿钟点，待排期核定）

| 时段 | 环节 | 负责人 | 要点 |
|---|---|---|---|
| 9:20—9:25 | 演练前动员：信号、路线、集合点、防踩踏要求 | 各班班主任 | 幼儿知道"跟着老师、弯腰捂口鼻"，不喧哗不推挤 |
| 9:25 | 触发响应：模拟起火点由发现人示警 → 报总指挥 → 宣布启动 → 广播 / 哨声通报，各组就位 | 总指挥 / 发现人 | 情境设定，不点燃明火；发现人与通报方式按本场确认 |
| 9:25—9:32 | 警报带队，按预定路线撤离 | 楼层引导员：配班老师 | 教师一前一后带队，清点员随班 |
| 9:32—9:40 | 集合点清点人数，报总指挥 | 各班清点员：班主任 | 与名册核对，缺员立即上报 |
| 9:40—9:45 | 现场小结：顺畅点与改进点 | 总指挥：副园长 | 只记事实与改进点，不做评价性结论 |
| 9:45—9:50 | 有序带回教室 | 各班班主任 | — |

- **分工**：总指挥：副园长；楼层 / 通道引导员：配班老师；班级清点员：班主任；医务 / 联络：保健医；器材保障：安保主任；拍照留痕：行政（各岗位姓名待核定）。

## 六、安全注意事项与红线

1. **幼儿不参与明火与器材实操**：本场幼儿只跟随疏散与观摩；器材动手训练仅限成人，另排专场。
2. **防踩踏优先**：通道分流向，不在楼梯口停留或围观器材演示。
3. **条件以现场为准**：器材完好性、通道畅通、值守配置以现场核查和持证要求为准；人数、器材数量、场地条件【待核实】，不预设。
4. **不写结论性表述**：不出现"零隐患""全部达标""保证不出事""百分百安全"；问题进整改闭环。
5. **方案不替代制度文件**：日常检查巡查、应急预案、设施维护按园所既有制度和属地要求执行。
